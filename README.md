An exploration of how learning data can reveal recurring difficulties, support evidence-based diagnoses, and help evaluate whether interventions work.

### Second Thought — Decision Intelligence

**The question:** How can we think through decisions more clearly?

A project exploring structured reasoning through facts, assumptions, options, trade-offs, and predictions.
